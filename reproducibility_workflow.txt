The following presents the reproducibility workflow for the sensitivity analysis to
the hyperparameter F, representing the number of layers used to fit the model's
Neural Network Gaussian Processes in the manuscript, 
"Integrative Learning of Dynamically Evolving Multiplex Graphs and Nodal
Attributes Using Neural Network Gaussian Processes with an Application
to Dynamic Terrorism Graphs". In particular, the code reproduces
the three tables, with their subtables, from the “Sensitivity to F” portion 
of the “Sensitivity Analysis” section of the manuscript.


The code is run in R, with R version 4.5.1. 


The R packages used and their versions are: 
  - MCMCpack (version 1.7.1)
  - gdata (version 3.0.1), 
  - BayesLogit (version 2.1)
  - mvtnorm (version 1.3.3), 
  - pROC (version 1.18.5)
  - caret (version 7.0.1)
  - doParallel (version 1.0.17)
  - foreach (version 1.5.2)
  
The simulated datasets, used for reproducing the sensitivity analysis of F, are stored in
.RData files, under the "data" folder.

The main script, used to replicate the tables in the sensitivity analysis to F,
is in the "code" folder. Its named:

  - main_script_F_sensitivity_analysis.R
  
  
This script uses doParallel and foreach to run different simulation cases and 
replications in parallel. The number of cores used was 6, but this can be customized through 
the variable “n_workers” on line 79. The script will also create a subfolder, 
named "outputs", if it does not already exist, where it stores .RData files containing
intermediate results from different model runs. At the end, the script, aggregates all of
the results for the three different cases of the sensitivity analysis, and outputs three different 
sets of tables corresponding to these cases.Each set of tables contains one for AUC of
edge prediction, one for MSPE of nodal attribute prediction, one for 95% prediction 
interval coverages for nodal attributes, and one for 95% prediction interval lengths
for nodal attributes. 

The results of running the script "main_script_F_sensitivity_analysis.R" are
under the "output" folder, in the file:

  - main_script_F_sensitivity_analysis_code_outputs.txt

Note: The implementation for the proposed method, DJL, is in the "incomplete_graphs_model.R" 
file, under the “code” folder, as discussed further below.

The remaining files in the “code” folder, are used for simulated data generation, 
intermediate calculations, fitting the model on given data, obtaining prediction results
for each model fit, and aggregating all of the results for the sensitivity analysis to F. 
The files and their roles are: 

  - These files contain fuctions for generating simulated data under data generation
  scenarios 1, 2, and 3 of the manuscript. The sensitivity analysis of F presented here,
  made use of "simulated_data_generation_nngp_layerwise_missingness.R" to generate the data 
  under scenario 1:
  
    - simulated_data_generation_nngp_layerwise_missingness.R (scenario 1)
    - simulated_data_generation_layerwise_missingness.R (scenario 2)
    - simulated_data_generation_tergm_layerwise_missingness.R (scenario 3)


  - The file "model_development.R", contains intermediate calculations and operations,
  used in data generation, and for fitting DJL in the file "incomplete_graphs_model.R": 
  
    - model_development.R
    
    
  - The file "incomplete_graphs_model.R", contains the code for fitting the DJL model
    using the given dynamic multiplex graph, C_arr, and nodal attributes, x_arr. It outputs the
    resulting MCMC samples for the model parameters, which can then be processed 
    to obtain results for prediction and uncertainty quantification:
  
    - incomplete_graphs_model.R
    
    
  - The file "model_generation_running_and_testing_functions.R", contains functions to 
   fit the DJL model and then obtain prediction and uncertainty quantification results,
   using either given data, or simulated data: 
    
    - model_generation_running_and_testing_functions.R
    
    
  - The file "F_sensitivity_results_function.R", contains a function for aggregating
  results from different replications of the analysis of sensitivity to F, for a particular
  set of data generating parameters that define a case:
  
    - F_sensitivity_results_function.R
